## 🎯 Общая концепция и возможности

**Footbalmonitor Pro** — современная многопользовательская веб-платформа реального времени для профессионального лайв-мониторинга футбольных матчей, скальпинга, тестирования стратегий и автоматической отправки сигналов в Telegram.

### Ключевые возможности:
- 👥 **Личный кабинет для каждого пользователя**: изолированные фильтры, независимый пул ботов, персональные пресеты и рекламные настройки.
- 🤖 **Мульти-бот система**: пользователь может привязать неограниченное число Telegram-ботов и каналов, а также гибко назначить конкретного бота на конкретный фильтр.
- 📢 **Рекламная платформа**: рекламные плашки (Top Ribbon, In-Feed, Sidebar) с поддержкой промокодов, брендирования и управления показами.
- ⚡ **35 предустановленных фильтров**: ТБ, ТМ, Доминирование, Прессинг, Угловые, Гол в раздевалку, Камбэк фаворита и др.
- 📊 **Источники данных**: поддержка Flashscore Live, SStats.net, Sofascore, API-Football и внутренних Webhook-шлюзов.
- 🛡️ **Умный дедупликатор сигналов**: защита от спама (1 на матч, кулдаун, при смене счёта) + авто-редактирование исходов в Telegram по окончании матча.
- 🧪 **Бэктестинг & ROI трекер**: историческое тестирование алгоритмов с расчётом PnL, винрейта и максимальной просадки.
- 🧠 **AI-Аналитик на базе Google Gemini**: моментальный разбор матча в один клик с формированием прогноза и коэффициентов.

## 👥 Многопользовательская система (Multi-Tenant & Личный кабинет)

### Принцип изоляции:
Каждый пользователь работает в полностью изолированном контексте:
- Все фильтры пользователя имеют маркер `userId`.
- При переключении пользователя система загружает его персональный набор фильтров (`footbalmonitor_filters_user_<ID>`), не затрагивая настройки других пользователей.
- Все созданные Telegram-боты привязаны к конкретному аккаунту в массиве `user.telegramBots`.

### Компоненты:
- **`src/components/PersonalCabinetView.tsx`**:
  - Вкладка **«Мои Telegram-боты»**: добавление бота, ввод Token и Chat ID, выбор бота по умолчанию, мгновенная проверка связи (Test Ping), удаление и редактирование.
  - Вкладка **«Профиль & Тариф»**: имя, email, статус подписки (FREE, PRO_ANALYST, VIP_CLUB), статистика привязанных стратегий.
  - Вкладка **«Переключение аккаунтов»**: возможность переключиться на любого пользователя из списка или создать новый аккаунт с индивидуальными настройками.
  - Вкладка **«Рекламные баннеры»**: управление рекламными плашками, переключение показов спонсорских блоков, промокоды.

### Модели данных (`src/types.ts`):
```typescript
export interface UserProfile {
  id: string;
  username: string;
  displayName: string;
  email: string;
  avatarUrl?: string;
  role: 'USER' | 'PRO' | 'ADMIN';
  plan: 'FREE' | 'PRO_ANALYST' | 'VIP_CLUB';
  telegramBots: TelegramBotProfile[];
  adPreferences: {
    showBanners: boolean;
    tier: 'standard' | 'partner' | 'ad_free';
  };
}

export interface TelegramBotProfile {
  id: string;
  name: string;
  botToken: string;
  channelId: string;
  isDefault?: boolean;
  notes?: string;
  verified?: boolean;
  lastTestedAt?: string;
}
```

## 🤖 Привязка Telegram-ботов к фильтрам

Пользователь может привязывать отдельные боты к определенным фильтрам:

### 1. Как это настраивается:
- **На карточке фильтра** (вкладка «Фильтры»):
  Выпадающий селектор **«Бот»** позволяет в один клик выбрать:
  - `🤖 По умолчанию` — используется дефолтный бот пользователя.
  - `🤖 <Имя Бота>` — любой бот из пула пользователя (например, *«VIP Сигналы»*, *«Corner Alert Bot»*).
  - `⚙️ Кастомный бот` — индивидуальные креды.
- **В Конструкторе фильтра** (`FilterBuilderModal.tsx`):
  Специальный блок **«Привязка Telegram-бота»** с радиокнопками выбора профиля бота либо ручным вводом уникального Bot Token и Chat ID именно для этого фильтра.

### 2. Маршрутизация сигналов в реальном времени (`src/App.tsx`):
При срабатывании условия матча диспетчер сигналов:
1. Проверяет наличие `rule.customBotToken` и `rule.customChatId`.
2. Если нет — ищет бота по `rule.botId` в `currentUser.telegramBots`.
3. Если нет — берёт бота по умолчанию (`b.isDefault`) у текущего пользователя.
4. Отправляет сигнал через `/api/telegram/send` с токеном и chat_id целевого бота.
5. Записывает `botName`, `botId`, `userId` в объект `SignalAlert`, отображая бейдж бота в истории сигналов.

## 🎯 Движок фильтров и 35 готовых стратегий

Файлы: `src/algorithms.ts`, `src/data/defaultFilters.ts`, `src/components/FilterBuilderModal.tsx`.

Включает 35 готовых проверенных лайв-стратегий, разбитых по категориям:
- ⚽ **Голы и Тоталы** (ТБ 0.5 1-й тайм, ТБ 1.5/2.5 в матче, Поздний гол 75'+, ТМ 2.5 сушка)
- 🔥 **Доминирование & Прессинг** (Шквал атак при 0:0, Камбэк фаворита, Андердог в меньшинстве)
- 🤝 **Обе забьют (ОЗ / BTTS)** (ОЗ Да, ОЗ Нет при счёте 1:0)
- 🚩 **Угловые** (Гонка угловых, Высокий темп корнеров, Дожим на последних минутах)
- 🟨 **Карточки и Фолы** (Грубый матч, Дерби, Красная карточка фаворита)
- 📈 **Индексы давления и xG** (Pressure Index > 75, Аномальный перекос владения)

Конструктор фильтров поддерживает:
- Точный выбор минуты матча (от / до).
- Счёт (0:0, ничья, лидерство хозяев/гостей, разница в 1 мяч, тотал голов).
- Разница опасных атак (Home - Away или Away - Home).
- Разница ударов в створ, угловых, владения мячом.
- Фильтры по лигам (разрешенные / черный список).
- Коэффициенты БК (исход П1, П2, Х, Тотал).

## 🌐 Источники данных (Data Sources)

Файлы: `server/dataSources.ts`, `src/components/DataSourcesModal.tsx`.

1. **Flashscore Live**: прямое подключение к протоколу Flashscore с парсингом инцидентов, угловых, ударов, атак.
2. **SStats.net API**: интеграция с сервисом футбольной статистики (live-статистика, рейтинги Glicko, H2H).

5. **Встроенный Демо-симулятор**: генерация реалистичных сценариев матчей для отладки и демонстрации.

## 🛡 Диспетчер сигналов, Анти-спам и редактирование в TG

Файлы: `server.ts`, `src/App.tsx`.

### 1. Анти-спам (Deduplication)
Чтобы бот не заспамил канал одинаковыми сообщениями каждую минуту:
- **`once-per-match`**: ровно 1 сигнал за весь матч для данного фильтра.
- **`cooldown`**: настраиваемая пауза (например, 15 минут) между повторными сигналами.
- **`score-change`**: повторный сигнал допускается только при изменении счёта.

### 2. Редактирование сообщений в Telegram (`/api/telegram/edit`):
- При отправке сигнала система сохраняет `telegramMessageId`.
- По завершении матча или смене исхода система отправляет запрос на редактирование оригинального сообщения в Telegram:
  - Проставляется итоговый счёт матча.
  - Добавляется бейдж: `✅ СТАВКА ЗАШЛА (WIN)` или `❌ СТАВКА НЕ ЗАШЛА (LOSS)`.
  - Рассчитывается чистая прибыль в рублях и флетах.

## 🚀 Запуск, сборка и переменные окружения

```bash

npm run dev

# Проверка типов
npm run lint

# Сборка для продакшна
npm run build

# Запуск собранного приложения
npm start
```
